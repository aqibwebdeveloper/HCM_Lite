# HCM Lite — Responsive UI Starter

A seven-page HTML5/CSS3 visual prototype for the Saylani HCM Lite hackathon.

## Open
Open `index.html` in a browser. Use the **Preview Admin Dashboard** link to explore the pages.

## Important
This is **UI only**, not a working HR system. Example data appears only to show layouts. Forms, authentication, role protection, attendance, leave approvals, storage, dynamic payslips and smart helper replies are not implemented. Mobile sidebar and payslip printing work.

## Pages
`index.html` and `pages/{admin,employees,leaves,settings,employee,payslip}.html`. Shared styles: `css/style.css`. Minimal mobile menu JS: `js/ui.js`.
